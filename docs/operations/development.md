# Development

PunchPress is a Bun workspace with a headless editor engine, shared document
schema, Vite web app, and Electron desktop shell.

## Workspace

| Package | Role |
| --- | --- |
| `packages/engine` | Headless `Editor`: state, commands, tools, geometry, history, export. |
| `packages/punch-schema` | `.punch` schema, load/save, normalization, version checks, font descriptors. |
| `apps/web` | React editor, canvas UI, panels, browser platform adapters. |
| `apps/desktop` | Electron main/preload, native menus, file opening, updater, packaging. |

## Setup

```bash
bun install --frozen-lockfile
```

Use the root package scripts. Do not swap package managers.

## Common Commands

| Task | Command |
| --- | --- |
| Web dev server | `bun run dev` |
| Web dev server, explicit | `bun run dev:web` |
| Electron dev shell | `bun run dev:desktop` |
| Web production build | `bun run build:web` |
| Default build | `bun run build` |
| Signed desktop build | `bun run build:desktop` |
| Unsigned desktop package | `bun run build:desktop:unsigned` |
| Preview built web app | `bun run preview` |
| Lint | `bun run lint` |
| Type/check/fix workflow | `bun run check`, `bun run fix` |
| Docs routing | `bun run docs:list` |

## Default Development Loop

1. Run the narrow command that exercises the changed surface.
2. Run `bun run lint` for changed TypeScript/React work.
3. Run `bun run docs:list` after docs changes.
4. Use the desktop commands only when Electron, native menus, local files,
   updater, or packaging behavior is part of the change.

## Local Artifacts

Generated benchmark and trace artifacts live under `.context/performance/`.
Release builds and packaged desktop artifacts are generated by the desktop app
tooling and should not be committed unless a workflow explicitly says so.
