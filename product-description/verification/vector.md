# Verification: vector tools and structure

Use a fresh disposable document for each destructive or interruption check. Mouse means macOS mouse/trackpad pointer plus keyboard; device checks require physical touch/stylus or a labeled event harness. Use 100% zoom unless the row says otherwise. Coordinates are screen positions on unobstructed canvas; move the setup if chrome overlaps those positions. Read [the protocol](README.md) before recording results.

Results remain unrun except the explicitly attributed coordinator browser observations. A source test is not a visual pass. For discrete Group/Compound commands, the extended interrupt setup means a subsequent body or child edit; no asynchronous command phase is implied.
