## Findings considered and rejected (do not re-audit)

- **Canvas pointer listener leak** (`canvas.tsx` press handlers): handlers
  self-remove on pointerup/pointercancel; per-press closures are by-design.
- **Brush `ready` race dropping early stroke points** (`brush-tool.ts:416-474`):
  points queue in `this.points`; the ready promise flushes and commits them.
  Correct by design.
- **Font catalog error swallowing** (`editor.ts:2138-2154`): catch resets the
  promise for retry; `editor-lifecycle.ts` sets error state. Works as intended.
- **Auto-updater missing signature verification**: electron-updater on macOS
  validates the downloaded app's code signature against the running app by
  default. Accepted as-is.
- **Clipboard JSON ReDoS / size limits**: speculative; local-first app,
  user-initiated paste. Not worth the complexity.
- **`.env.example` "credential exposure"**: placeholder values in an example
  file are standard practice; `.gitignore` covers `.env*` variants.
- **History entries split across multi-write ops**: no concrete evidence
  found; revisit only if a real mis-grouped undo repro appears.
